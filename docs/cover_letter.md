# Cover Letter Draft

Dear Editor,

We submit the pilot manuscript **Evidence-linked Spatial and Treatment-State
Features in EGFR-Mutant Lung Adenocarcinoma** for consideration as a
computational/translational oncology study.

This work assembles and audits public treatment-state cohorts rather than
claiming a clinical decision rule. The primary resources contain matched
Xenium treatment-naive/progressive-disease sections and single-nucleus
TN/MRD/PD metadata from EGFR-mutant lung adenocarcinoma. We preserve the
patient/sample unit of replication, freeze panel-aware resistance signatures,
and separate metadata proxies from gene-expression scores.

The main result is a reproducible framework showing exploratory associations
between treatment state, lineage plasticity, EGFR resistance metadata, and cell
composition. The work does not claim osimertinib efficacy, causal
pharmacological sanctuaries, or patient-level treatment recommendations.

All code, derived reports, tests, figures, provenance records, and manuscript
materials are openly available at:

https://github.com/Lukecele/spatial-continuum-translational

The project concept is archived at Zenodo:

https://doi.org/10.5281/zenodo.23956445

We believe the manuscript is appropriate for a venue interested in reproducible
computational methods and hypothesis-generating translational oncology.

Sincerely,

Luca Celebrano
